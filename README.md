# CodeOrbit Tech Internship — Project 1: Rule-Based Chatbot

## Overview
A beginner-friendly chatbot built with Python. It responds to greetings and common questions using predefined rules, keyword matching, and `if` statements.

## Features
- Greeting responses
- Answers to common questions about Python, internships, and the project
- Simple identity and help responses
- Fallback response for unknown input
- Exit using `bye`, `goodbye`, `exit`, or `quit`
- Comments explaining the program
- No external packages required

## Requirements
- Python 3.8 or newer
- IntelliJ IDEA with Python support configured, or another Python IDE

## Run in IntelliJ IDEA
1. Extract `CodeOrbit_Rule_Based_Chatbot.zip` to a folder.
2. In IntelliJ IDEA, choose **File → Open** and select the extracted `CodeOrbit_Rule_Based_Chatbot` folder.
3. Ensure the project has a Python interpreter configured:
   **File → Settings → Project → Python Interpreter** (menu names may vary by IntelliJ version).
4. Open `chatbot.py`.
5. Right-click inside the file and select **Run 'chatbot'**.
6. Type messages in the Run console. Type `bye` to stop.

## Example
```text
Bot: Hello! I am CodeOrbit Bot.
You: hi
Bot: Hello! How can I help you today?
You: what is python
Bot: Python is a beginner-friendly programming language...
You: bye
Bot: Goodbye! Thanks for chatting with me. Have a great day!
```
